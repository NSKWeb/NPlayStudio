About Us

Last updated: 2026-10-17

NPlayStudio is a small, independent project with one goal: make everyday media tasks fast and free.

Why it exists

Most online converters hide a paywall behind the download button, add watermarks, or cap the file size so aggressively the tool is useless for real work. We wanted the opposite: drop a file in, get a result, download it, close the tab. No account, no watermark, no upsell.

How it works

Everything runs on a single small server:

  • FFmpeg handles all video and audio work — transcoding, concatenation, palette-optimised GIFs.
  • Pillow handles image compression, conversion and cropping.
  • FastAPI exposes the API and serves these pages.
  • Redis and ARQ queue jobs so a long conversion never blocks the site.
  • SQLite stores anonymous task metadata and the usage counters on the dashboard.

Privacy by default

Uploaded files are deleted automatically one hour after the task is created. We do not look at your content, and we do not build profiles of what you convert.

How it stays free

Advertising, served by Google AdSense, covers the server bill. That is the whole business model. Ads load only after you accept the consent banner — choose "Essential only" and no ad scripts run at all.
